# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially when discussing security false positives.
- Keep examples and reports free of real secrets.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private credentials, tokens, or sensitive MCP configs.
- Repeated off-topic demands after maintainers have asked to pause.

## Enforcement

Maintainers may edit, hide, or remove comments and may temporarily or permanently ban contributors for behavior that harms the project community.

Report concerns privately through the repository maintainer profile or GitHub security advisory flow when sensitive details are involved.
