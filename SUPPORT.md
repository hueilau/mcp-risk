# Support

Use GitHub issues for bugs, false positives, rule requests, and documentation fixes.

## Before Opening An Issue

- Redact secrets, tokens, URLs, and private paths from MCP config snippets.
- Include the command you ran.
- Include the relevant output.
- Say whether you expected `check` or `scan` behavior.

## Security Issues

Do not open public issues for vulnerabilities or leaked secrets. See [SECURITY.md](SECURITY.md).
